Make it once, use it many times

You're making brilliant things with Claude and then forgetting how you made them, as Laetitia put it. Keep the recipe every time. And when learners start using what you make, have Claude make it once and save it, so the cost doesn't grow with every learner who clicks.

Two ways to put AI in front of learners

Your team uses Claude on a subscription: a fixed amount a month per person. Learners don't have subscriptions, so anything that runs Claude live for a learner goes through the API, and every use is charged.

Subscription or API

The same work costs very different amounts depending on how you pay for it.

SubscriptionAPI
Who it's forYour team, building and checkingLearners and other systems, live
How you payA fixed amount per person per monthPer use, by how much text goes in and out
Use it forEverything you make: clips, hints, question banks, marking briefsOnly what must answer live: a tutor chat, a first mark on a new portfolio
Keep it safeUse it fully every month, it's part of learningA monthly spending cap, and someone reads the bill

Keep the recipe

When Claude gets something right, it knows exactly how it did it, for as long as that chat lasts. Ask it to write the steps down before you close the chat.

  1. Get it right onceWork in the chat until the clip, deck or question bank is what you want.
  2. Ask for the recipeClaude writes the steps as a .md file and turns anything that repeats into a small script.
  3. Save it with the workIn your project folder, under recipes/, so the team can find it.
  4. Use it next time"Follow recipes/clip-from-guide.md for Module 3." Same result, much faster.
hsa-content/
  recipes/
    module-old-to-new.md       # Elsa: old module to new, with placeholders
    clip-from-guide.md         # storyboard, build, voice, check
    questions-to-moodle.md     # Christine: learner guide activities to Moodle XML
    hints-for-questions.md     # three hints per question
  scripts/
    join-clips.py              # runs on your computer, no Claude needed
  hsa-video-style.md

Let your computer do the heavy work

Cutting video, joining clips, adding audio or converting 200 files doesn't need Claude to think. Ask Claude to write a script once, then your computer runs it as often as you like, and your Claude allowance isn't touched. You'll hear the fan.

Video

Join shots into one clip, trim the start, add the voice track, export for Moodle.

Audio

Split one narration file into one file per slide, even out the volume.

Files

Rename and sort a folder of learner guides, convert Word to PDF, shrink images.

Before anything with live AI reaches learners

  • Does it need to answer live? If the answer can be written in advance, write it in advance.
  • What's the most it could cost? Learners, times uses per learner, times the cost per use. Ask Claude to work it out with you, and to show the sum.
  • Is there a cap? A monthly spending limit is set before launch.
  • Whose data goes in? Learner work goes only through an account where it isn't used for training, agreed with IT and FPD under POPIA.
  • Who checks it? It goes through the check like anything else that goes live.

Prompts to copy

1 · Write down the recipeThat worked. Write down exactly how we got here as recipes/clip-from-guide.md: the inputs, each step, the prompts that worked, the checks and the mistakes to avoid. Turn any step that will be the same every time into a script in scripts/. Then tell me in two lines how to use the recipe next time.
2 · A script for heavy workWrite a script I can run on my own computer that joins the clips in shots/ in order, adds voice.mp3, and exports one MP4 for Moodle. Tell me what to install first, step by step for Windows, and how to run it.
3 · What would it cost?We're thinking about a live tutor for Stock Receiving. Help me estimate the monthly cost through the Claude API: ask me how many learners, how often they'd use it and how long a typical exchange is, look up the current prices, and show the sum line by line with a low, middle and high case.
