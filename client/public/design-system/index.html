Create a design system in Claude

Give Claude your brand once, and every deck, page and design it makes from then on uses your colours, fonts and rules. Four steps from the Claude app home.

Step 01

Where Claude Design went

Claude Design used to be its own app at claude.ai/design. It has now been merged into Artifacts, so a design system is something you make and use inside any Claude chat.

The change is reaching accounts at different times, so what you see depends on yours. Some people have a Design item in the left sidebar and some don't yet. That's fine: the route in this guide starts from the Claude app home and works for everyone.

Made design systems in the old Claude Design? Open Design in the sidebar and click Move team design systems to bring them across. The standalone claude.ai/design closes by 14 December 2026.

On Enterprise, an owner has to switch design systems on first, in Organisation settings, then Artifacts. On Pro, Max, Ultra and Team they're on already.

Step 02

Start from the Claude app home

Click New in the sidebar to get to the home screen, then open the + menu under the message box.

Step 03

Choose Using Claude

Two choices come up. Pick Using Claude unless your design system already lives in code.

Step 04

Follow the wizard

The wizard opens with a chat on the left and your design system page on the right. First it asks what to build it from.

Real examples beat a spec. A finished deck or a landing page you're proud of tells Claude more than a list of hex codes. The first draft is small on purpose. If it misses your brand, upload more and ask Claude to try again.

Step 05

Use it in your next chat

Open the + menu, hover over Design system and tick yours (Fig. 2). Ask for a deck, a one-pager or a design and Claude builds it in your brand.

To change it later, open Manage design systems from the same menu, or go to Settings, then Capabilities and click Manage next to Design systems.

If your account has the Design item in the sidebar, you'll find a Design System tile there too. It opens the same wizard.

Step 06

In the app or in code?

Use the app if your brand lives in files, a design tool or your head. Use Claude Code if your design system is already built as code, with React components and tokens, so Claude designs with exactly what you ship.

Doing it in code

  1. Set up VS Code with Claude Code (the VS Code setup guide shows how) and sign in with the same Claude account you use in the app.
  2. Open the folder that holds your component library.
  3. In the Claude Code panel, type /design-sync and send it. Claude Code finds your tokens and components and lists them.
  4. Pick the components to include. Claude asks before it runs your project's build, because it needs to render each one to make its preview.
  5. Check the plan. Before it writes anything, it shows you the exact files it'll send to your design system, and you approve them.
  6. Back in the Claude app, your design system is in the + menu under Design system, ready to use.

No component library yet? Start in the app. You can add the code route once your components exist and keep both in step by running the sync again.
