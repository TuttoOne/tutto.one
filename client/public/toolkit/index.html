The Claude toolkit

Claude on its own can read and write text. The extras on this page let it open a PDF, fill in a spreadsheet, read a scanned page or cut a recording, so here's everything on my machine, what each one does and which ones you need.

VS Code extensions

Add these in VS Code: open the Extensions panel (the four squares on the left), search for the name and check the publisher matches before you click Install. Copycat extensions with similar names do turn up.

  • Claude Codeanthropic.claude-codeClaude in a panel beside your files. It reads the folder you have open, makes changes you can see and asks before it does anything big.Get it
  • PDF Previewtomoki1207.pdfOpens a PDF in a VS Code tab so you can check what Claude quotes without switching apps. Claude reads PDFs without it: this one is for you.Get it
  • Rainbow CSVmechatroner.rainbow-csvColours each column of a CSV file so an export from Moodle, your CRM or a spreadsheet is readable before you hand it to Claude.Handy
  • YAMLredhat.vscode-yamlUnderlines mistakes in YAML, the format a lot of settings files and skill files use, so a missing space doesn't break them without you noticing.Handy
  • Remote SSHms-vscode-remote.remote-sshOpens a folder on another computer, a server for example, as if it were on your laptop. Claude then works on that machine. Comes with Remote SSH Editing and Remote Explorer.Builders
  • Dev Containers and Container Toolsms-vscode-remote.remote-containers · ms-azuretools.vscode-containersRuns a project inside Docker so it behaves the same on every machine, and lets you see what's running.Builders
  • Kubernetesms-kubernetes-tools.vscode-kubernetes-toolsFor the client projects that run on a Kubernetes cluster. You won't need it.Builders

Also on my machine, you don't need these

  • Other AI assistantsopenai.chatgpt · google.gemini-cli-vscode-ide-companion · google.google-antigravity · mistralai.mistral-vibe-codeI keep ChatGPT, Gemini and Mistral installed to compare them with Claude for clients. One assistant is plenty when you're learning.Builders
  • Claude Speakbuilt by Tutto, so it isn't on the marketplaceReads Claude's answers aloud with the Mac's built-in voices. I built it for myself, so ask if you'd like a copy.Handy

Command-line tools

These are small programs Claude runs behind the scenes when you ask it to do something. You rarely type them yourself: you ask, Claude runs the command and shows you what it did.

Everyday

  • Pythonpython3The language Claude reaches for when a job needs real work on a file: totting up a spreadsheet, filling in a Word template, splitting a PDF. Most of what's in the Python section below runs on it.Get it
  • GitgitKeeps a history of every change to a folder, so you can see what Claude changed and undo it. It's your safety net.Get it
  • Node.jsnode · npm · npxRuns a lot of the connectors that plug Claude into other apps, and the websites we build together.Handy
  • uvuvInstalls Python and Python tools quickly and keeps each project's libraries separate, so one project can't break another.Handy
  • HomebrewbrewThe Mac's app store for command-line tools. One line installs anything else on this list. On Windows, winget does the same job.Handy
  • GitHub CLIghLets Claude save your work to GitHub, open a pull request or read an issue without you leaving VS Code.Handy
  • ripgrep and jqrg · jqripgrep searches thousands of files in a second. jq reads and reshapes JSON, the format most apps export. Claude uses both to find things fast.Handy

Documents, scans and audio

  • Popplerpdftotext · pdftoppmPulls the text out of a PDF and turns pages into images. Helps Claude with long or awkward PDFs.Handy
  • Tesseracttesseract · tesseract-langReads the words in a scan or a photo of a page (OCR), in many languages. Use it when a PDF is really a picture of a page.Handy
  • FFmpegffmpegCuts, joins, shrinks and converts audio and video. Claude uses it to trim a recording or pull the sound out of a video.Handy
  • whisper.cppwhisper-cliTurns a recording into a transcript on your own computer, so the audio never leaves it.Handy

For building and running apps

  • DockerdockerRuns a database or a whole app in a sealed box on your laptop, so I can test a site before it goes live.Builders
  • Azure CLI and Supabase CLIaz · supabaseTalk to the cloud services some client projects run on.Builders
  • llama.cpp and Hugging Face CLIllama.cpp · hfDownload and run open AI models on the laptop itself, for testing what works offline.Builders
  • browser-usebrowser-use (via uv)Lets an AI drive a web browser: click through a site, fill in a form, check a page works.Builders
  • LiveKit CLIlivekit-cliFor voice agents, the AI you can talk to on a call.Builders
  • Otherscodex · mistral-vibe · xcodegen · mas · even-terminalOther assistants' command-line versions, iPhone app tooling, Mac App Store installs and smart-glasses tooling. You can skip all of these.Builders
Install the everyday set on a Mac
brew install python git node uv gh ripgrep jq poppler tesseract tesseract-lang ffmpeg whisper-cpp

Get Homebrew first from brew.sh. On Windows: winget install Python.Python.3.13 Git.Git OpenJS.NodeJS.LTS astral-sh.uv GitHub.cli, or ask Claude to do it.

Python libraries

Add-ons for Python. Each one teaches Claude to handle one kind of file properly, so it edits your actual Excel or Word file and the layout stays as you left it.

Office files

  • openpyxlopenpyxl · et_xmlfileReads and writes Excel files, formulas and formatting included. This is how Claude fills in a spreadsheet you already have.Get it
  • python-docxpython-docxReads and writes Word documents: headings, tables, styles. Claude uses it to turn your guides into clean text and to fill in a template.Get it
  • ReportLabreportlabMakes new PDFs from scratch: certificates, handouts, a report in your colours.Handy

PDFs, scans and images

  • PyMuPDFPyMuPDF (imported as fitz)The fastest way to read, split, merge and search PDFs. It also pulls out the images and tells you which page a line is on.Get it
  • pdf2image and pytesseractpdf2image · pytesseractTurn PDF pages into pictures, then read the text in them. Together with Poppler and Tesseract above, this handles scanned documents.Handy
  • PillowpillowResizes, crops and converts images, screenshots for a handout for example.Handy
  • lxmllxmlReads HTML and XML quickly. Word and Excel files are XML inside, so the other libraries lean on it.Handy

Audio and the rest

  • Whisperopenai-whisper · torch · tiktoken · numba · numpyThe Python version of the transcriber above. It's a big download (torch alone is over a gigabyte), so only add it if you transcribe a lot.Handy
  • Requestsrequests · certifi · urllib3 · idna · charset-normalizerFetches a web page or talks to an app's API. The four small ones come with it.Handy
  • Jinja2Jinja2 · MarkupSafeFills a template with your data, for example 30 personalised letters from one spreadsheet.Handy
  • SymPy and NetworkXsympy · mpmath · networkxMaths and maps of how things connect. They came in with other tools: you won't use them directly.Builders
Install the office and PDF set
python3 -m pip install openpyxl python-docx PyMuPDF reportlab pdf2image pytesseract pillow

On Windows type py in place of python3.

The easy way to install any of this

Ask Claude. Type "Install openpyxl and python-docx so you can work with my Excel and Word files" into the Claude Code panel. It checks what you already have, runs the commands and asks before each one, so you can say no.

Start with the ones marked Get it, then add the rest when a job needs them. If anything fails, copy the error into Claude or email me and we'll find 15 minutes.
