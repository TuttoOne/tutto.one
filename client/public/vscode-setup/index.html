Step 01

Install VS Code

VS Code is a free editor from Microsoft. It is where Claude and Mistral will read and write your files.

  1. Go to code.visualstudio.com/download.
  2. Windows: download the User Installer and run it. Accept the licence, keep the default folder, leave Add to PATH ticked, then click Install and Finish. No admin rights needed.
  3. Mac: download the Universal build, open the .zip and drag Visual Studio Code into Applications.
  4. Open VS Code. You should see the empty window in Fig. 1.
Step 02

Find your way around the screen

Three areas matter: the file navigator on the left, your files in the middle, and the AI panel on the right. Four buttons in the top-right corner show and hide them.

The left side bar holds the Explorer, your file navigator. Open a working folder before you start, so the agents know where to work.

Use a practice folder. Create an empty folder such as Desktop/New for training. Keep real case files out of it until the team is comfortable with how the agents behave.

Step 03

Install the Claude and Mistral extensions

Step 04

Open the AI panel on the right

Keep the agents in the right side bar. Files stay on the left and you can watch both at once.

If an agent opens on the left or as a tab in the middle, drag its tab into the right side bar. VS Code remembers the position next time. The first time you open each agent, it asks you to sign in (Claude) or paste your API key (Mistral).

Sign in to Claude

You do this once. VS Code hands you over to your browser, you log in to your Claude account and approve the connection, then you come back to VS Code.

Step 05

Run a first task with Claude

Give Claude a task and watch the Explorer. New files appear on the left as Claude creates them.

CLAUDE.md is the briefing file. Claude reads it at the start of every session in that folder. Here it holds the commands and the rules: evidence goes in only through the tool, the custody log is append-only, and the kit is for lawful work only. Edit it to brief Claude on how your team works.

Step 06

Run a task with Mistral Vibe

Mistral works on the same folder. Switch tabs and give it a task; here it builds a reusable skill from what Claude produced.

Choose the approval mode on purpose. In these screenshots both agents run in Auto. That is fine in a practice folder. With real case material, use Manual in Claude and Ask in Mistral until you trust the workflow, so every command waits for your approval. In Fig. 18, Mistral reads files outside the open folder; agents can reach anything your user account can.

If something is missing

  • No layout buttons: right-click the title bar and tick Layout Controls.
  • Extension installed but not showing: search every command for Developer: Reload Window.
  • Claude says “Not logged in”: reload the window; the sign-in screen reopens.
  • Mistral asks for a key every time: rerun setup from the Mistral Vibe panel and paste the key once.
