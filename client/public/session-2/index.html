Point Claude at the file

"Summarise the Q3 accounts" makes Claude guess which file you mean. Name the file and it reads that one, and it can tell you which page each number came from. Here's the folder we use all session.

fenwick-rowe/CLAUDE.md
# Fenwick & Rowe: client work

- Before you make any document, read brand/BRAND.md and follow it.
- Every number says the file and page it came from.
- Can't find it? Write [NOT IN SOURCE].
- Not sure? Write [CHECK].
- Save finished files in output/. Never write over a file in sources/.
- Write like our past letters in brand/examples.

The rules file in our example folder, next to brand/, sources/, templates/ and output/. Copy it into your own folder and change the names.

  • Type @ and the file name

    Start typing @q3 in the Claude box and pick the file from the list. Works for folders too: @sources/

  • Send the open file

    With a file open in the editor, press Option K on a Mac or Alt K on Windows. Select some lines first and it sends just those, with their line numbers.

  • Copy the path

    Right-click any file in the Explorer, choose Copy Relative Path and paste it into your message.

The CLAUDE.md file is read at the start of every conversation in that folder, so the rules above apply to every job without you typing them again. When Claude asks to run a script, read what it says it will do, then say yes.

The same chart, twice

Same data, same request, one with the brand file and a clear brief. This is the example we use for "what good looks like": hours spent on the monthly client report, before and after the brief and scorecard went in.

  1. Title says what happened"Report time down from 6.5 to 2.2 hours", where the first try said "Chart 1".
  2. Colours mean somethingGrey for before, green for after. Six colours made you read a legend.
  3. Values on the barsNobody has to read numbers off an axis.
  4. Starts at zeroThe first try started at 2, so June's bar looked 24 times shorter than March's. The real gap is about 3 times.
  5. Says where it's fromA source line, so anyone can check it.
  1. The brief behind the good chartMake a bar chart of report hours by month from @output/run-log.xlsx. Follow @brand/BRAND.md. Title it with what the data shows, put the value on each bar, start the axis at zero and add a source line underneath. Save it as a PNG in output/.

From examples to a scorecard

Everything we checked today becomes a scorecard: the standard every piece of AI work on that job gets judged against. Here's Fenwick & Rowe's for the monthly client summary. Each check is something a colleague could tick without asking you.

#CheckHow you test itPass when
1No invented factsOpen 3 cited pages and find the numberAll 3 match
2CompleteCompare with last month's summaryEvery section there, gaps marked [NOT IN SOURCE]
3Totals add upClick the totals in the workbookFormulas, and they match the accounts
4On brandPut it next to a past reportSame colours, fonts and logo position
5Sounds like usRead the first paragraph aloudYou'd send it without rewording

"No invented facts" is always check number one. Four out of five is a fail: fix the brief or the brand file, then run it again. Build your own with the agent scorecard tool.
