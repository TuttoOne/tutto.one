Which place for which job

Same Claude, same account. The difference is what the work is for.

VS Code, in a folder

Best for content you build up and keep in files.

  • Learner guides, question banks, the gap lists
  • Rules in CLAUDE.md, the HSA format skill
  • Many files read together

The Claude app

Best for things you show people and things that repeat.

  • Artifacts: pages, charts and planners you can share by link
  • Projects: a set of files and instructions for one area, like board work
  • Scheduled tasks: a job Claude runs daily or weekly on its own

If the Word and Excel add-ins aren't available to you, the app is also the easiest way to work on a spreadsheet: attach it to a chat.

Artifacts: work you can open and share

An artifact is a page Claude builds next to the chat: a chart, a table, a calendar or a small tool. It opens in its own panel, you can keep changing it in the chat, and you can share it as a link. Use the word "artifact" in your request and Claude knows what you mean.

Sharing an artifact, and when not to

An artifact starts private. You choose who sees it.

Share a link

Use Share or Publish on the artifact. Anyone with the link can open it, and they don't need a Claude account. Good for a planner the team works from.

Make a file for the pack

For board papers, ask: "make this as a PowerPoint slide" or "as a Word page". The file goes in the pack like anything else.

Keep it private

A link can be forwarded. Don't share a link to anything board-confidential, any learner data or anything with salaries in it. Use the file instead.

Projects: the app's version of a folder

In VS Code your rules live in a CLAUDE.md. In the app the same idea is a Project: you give it instructions and files once, and every chat inside it starts with them.

A "Board" project could hold the risk register, last quarter's minutes and an instruction like "write for board members, one page, plain English, never guess a number". Then each board chat starts from there, and you stop attaching the same files every time.

Scheduled tasks: a job Claude does every week

You write the job once and pick how often. Claude runs it and the result waits for you under Scheduled. It works on your Pro account.

  1. Open the Claude desktop app and choose Scheduled in the left sidebar.
  2. Choose New task, then Create with Claude. Describe the job and how often. (In the newest version of the app you can just ask for it in any chat.)
  3. Answer Claude's questions, check the name, timing and instructions, then choose Schedule.
  4. Under Scheduled you can see past runs, edit, pause, delete or run it now.
