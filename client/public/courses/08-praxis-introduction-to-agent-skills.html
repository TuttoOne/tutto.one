Tutto.Lesson 1 · What it is
Lesson 1 — if you take one thing away

If you keep explaining it, write it down once

A skill is a folder of instructions. Claude holds only its one-line description until your request matches — then it loads the rest.

Personal skills (~/.claude/skills) follow you across every project; project skills (.claude/skills) ship in the repo for the whole team. The rule of thumb: if you find yourself repeating an instruction, that's a skill waiting to be written.

03
Tutto.Lesson 2 · Build one
Lesson 2

Build one: folder, file, restart

Create a directory, write SKILL.md, restart. Claude loads every skill's name and description at startup, then matches your request to them.

Claude loads only names and descriptions at startup, then asks you to confirm before pulling the full skill into context. If two skills share a name, priority decides — so keep names distinct.

04
Tutto.Lesson 3 · Build one
Lesson 3

Keep SKILL.md lean — split the rest out

Two fields are required, two optional. Past about 500 lines, move detail into supporting files Claude opens only when it needs them.

allowed-tools fences a skill — say Read, Grep, Glob, Bash only — for read-only or sensitive work. And tell Claude to run a script, not read it: the source never enters context, only the result does.

05
Tutto.Lesson 4 · Fit & ship
Lesson 4

Five tools, five jobs

Skills load on demand when your request matches. The other four solve different problems — pick by when each one fires.

Reach for a skill when knowledge should apply automatically the moment the topic comes up. CLAUDE.md is always-on standards; subagents isolate delegated work; hooks fire on events; MCP brings in outside tools. Most setups use several at once.

06
Tutto.Lesson 5 · Fit & ship
Lesson 5

Three ways to share — widest reach last

Commit to the repo for your team, publish a plugin for the community, or push enterprise-managed settings for the whole organisation.

One gotcha: subagents start with a clean context, so they don't inherit your skills. List them in a custom agent's skills: field. Built-in agents (Explore, Plan, Verify) can't use skills at all.

07
Tutto.Lesson 6 · Fix it
Lesson 6

When it breaks, it's one of five things

Run the validator first. Then match the symptom to its fix — most "won't trigger" problems are just the description.

Test the exact phrases you'd type — "why is this slow", "make this faster" — and add any that fail to the description. That single fix solves most triggering problems. Run claude --debug to see loading errors by name.
