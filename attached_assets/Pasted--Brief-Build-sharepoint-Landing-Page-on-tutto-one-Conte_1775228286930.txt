## Design Notes
- Match the existing tutto.one design system (fonts, colours, spacing)
- If the existing site is dark-themed, keep dark. If light, keep light.
- The page should feel technical but accessible — the audience is IT managers and operations directors, not developers exclusively
- Mobile responsive
- Fast loading — no heavy animations or massive images
- The audit prompt code block should look like a terminal/code editor (dark background, monospace font, copy button)

## Email Capture Backend
- Whatever the simplest approach is in the current stack:
  - If there's already a database or API: add an endpoint to store email + timestamp
  - If not: store to a JSON file, or use a free service like Formspree/Formspark
  - The email list will eventually move to a proper CRM, so just capture email + timestamp + source ("sharepoint-landing") for now
