### Chat Behavior

**Three conversation streams:**
1. "Learn about AI Readiness" → Educational flow from ai-readiness.md
2. "Run a quick diagnostic" → Interactive diagnostic (adapts to user's available time)
3. "Talk to Daniel" → Contact/booking flow → Calendly

**Conversation engine rules:**
- 90% scripted responses from flows.json
- Pattern match user input to intents
- Only call Haiku API when no intent matches
- Always provide suggested next actions (buttons or prompts)
- Typing indicator before responses (300-800ms delay for realism)
- Remember context within session (not across sessions)

**Personality:**
- Warm, direct, expert but approachable
- First person ("I help businesses...")
- Occasional light humor
- Never robotic or corporate
- Encouragement during diagnostic
